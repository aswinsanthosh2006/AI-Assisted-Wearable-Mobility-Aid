# Images

This directory contains images used in the project documentation.

| File | Description |
|:---|:---|
| `circuit-design.jpeg` | HC-SR04 + Raspberry Pi 4 wiring diagram. Shows GPIO pin connections (TRIG=GPIO24, ECHO=GPIO23), 1kΩ/2kΩ voltage divider, USB webcam, power bank, and earphone connections. From the project presentation slides. |
| `cap-concept.jpeg` | AI-generated concept illustration of the wearable cap form factor. **Not a photograph of the actual prototype.** Used for design visualisation only. |
| `multi-object-and-phone-detection.png` | Detection output from report Fig 4.1 (top) & 4.2 (bottom). Top: three simultaneous detections — `person 0.87`, `cell phone 0.75`, `car 0.54`. Bottom: isolated cell phone detection at 65% confidence. |
| `chair-detection.png` | Detection output from report Fig 4.3. Chair detected at 68% confidence with green bounding box. |
